🌍 COVID-19 Global Impact Dashboard

📌 Project Overview

The COVID-19 Global Impact Dashboard is a data analytics project designed to analyze and visualize the worldwide impact of the COVID-19 pandemic. It provides insights into confirmed cases, deaths, recoveries, and country-wise COVID-19 statistics through interactive charts and visualizations.

🎯 Objectives

- Analyze the global spread of COVID-19.
- Track confirmed cases, deaths, and recoveries.
- Compare COVID-19 statistics across different countries.
- Identify trends and patterns in the pandemic.
- Present meaningful insights using data visualization.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI / Excel (if used)

📊 Key Features

- Global COVID-19 statistics.
- Country-wise comparison.
- Total confirmed cases.
- Total deaths and recoveries.
- Interactive charts and graphs.
- Trend analysis and data visualization.

💡 Key Insights
